# Инструкции для агента Cursor (этот репозиторий)

## Прогресс задачи — обязательно в чате

Прогресс **не отображается в UI редактора** — его видно **только в тексте твоих ответов** пользователю.

При задаче с **двумя и более** смысловыми шагами (несколько файлов, серия правок, цепочка инструментов):

1. **Первая строка ответа** (до любого другого текста) — ровно в таком виде:
   - `Прогресс: k/N файлов` — если считаешь по файлам; **или**
   - `Прогресс: k/N шагов` — если файлов заранее неизвестно.
2. **Вторая строка** (опционально, если оценка уместна): `Ориентир: ~Xm до завершения` (или диапазон `~3–5 мин`).
3. В **каждом** следующем сообщении по той же задаче обновляй `k` (сколько уже сделано).

Пример начала ответа:

```
Прогресс: 2/7 файлов
Ориентир: ~4 мин до завершения

Дальше обычный текст…
```

Один простой шаг без плана — счётчик не обязателен.
